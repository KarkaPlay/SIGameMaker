# Правила интерфейса

- Сейчас проект предназначен только для горизонтального десктопного интерфейса.
- Не добавлять вертикальную мобильную компоновку и не сворачивать рабочие панели в одну колонку на узких экранах. Мобильная версия отложена.
- Минимальный размер текста — 14 CSS px. Сохранять свободное пространство и понятную иерархию.
- Проверять основной сценарий на горизонтальных экранах 1280×720 и 1440×900; структура не должна распирать страницу при большом количестве раундов, тем и вопросов.

- В редакторе вопрос выбирается только на одном игровом поле. Не дублировать выбор вопроса в боковых списках, мини-картах или предпросмотре. Сценарий выбранного вопроса расположен рядом с полем.
