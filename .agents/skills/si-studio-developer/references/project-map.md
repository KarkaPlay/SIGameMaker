## Команды из корня

- `npm start` — локальный сайт на порту 4173 через Python 3. Если сервер уже работает, используй его.
- `npm test` — тесты Node.js; для XSD нужен `xmllint`.
- `node --check si-studio/dist/app.js` — синтаксис изменённого модуля; аналогично для других JS.
- `npm run build` — готовая `cloudflare-upload/` без установки зависимостей и публикации. Не запускай без отдельной просьбы: пользователь сам собирает папку через `Собрать сайт.command`.

## Проверки по задаче

**UI:** 1280×720 и 1440×900; отсутствие прокрутки страницы в меню; ограниченные панели в редакторе и конструкторе; длинные названия и большие структуры; все подписи от 14 px; диалоги не закрываются от внутреннего клика; после редактирования остаются фокус и прокрутка.

**Сценарий:** выбор на единственном поле; добавление и редактирование шага; перенос, отмена и повтор; параметры/файл перемещаются вместе; отменённый перенос не меняет порядок; медиа и текст переживают перезагрузку.

**SIQ:** экспорт и обратный импорт текста, Unicode и XML-символов, всех видов встроенного медиа, длительностей, порядка, основного ответа и альтернатив; соответствие официальной схеме для поддержанного формата. Неподдержанный импорт не меняет черновик. XSD-проверка не заменяет реальный сеанс SIGame.

При изменении механики проверь актуальный код. Смотри не только допустимость шагов в XML, но и переходы состояний, передачу ответа клиентам, истечение времени и исчерпание попыток.
