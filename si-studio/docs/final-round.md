# Финальный раунд

Проверено 23.10.2026 по официальным исходникам SI, commit `7f8cda975fdd71aef69fa4eef0572d41417d8900`. Речь о классических правилах; настоящий сеанс SIGame Online не запускался.

В финале несколько тем, в каждой — один вопрос. Темы исключаются до последней; если тема одна, исключение пропускается. RemoveOtherThemesStrategy выбирает вопрос с индексом 0 оставшейся темы. Дополнительные вопросы этой темы в стандартном финале не используются. Настройка игры PlayAllQuestionsInFinalRound позволяет повторять выбор для оставшихся тем; это настройка игры, не повод добавлять несколько вопросов в тему. В режиме Quiz выбор может быть последовательным.

WellKnownGameRules назначает финалу тип по умолчанию StakeAll. ScriptsLibrary сначала собирает скрытые ставки, затем показывает содержимое и запрашивает прямые ответы. GameController обрабатывает удаление тем, скрытые ставки и проверку ответов; Viewer принимает Out и PersonFinalStake. В редакторе эти действия игроков не симулируются.

Важная деталь экспорта: `QuestionTypes.Default` — пустая строка, а не литерал `default`. В SIQ 5 у финального вопроса **опускается атрибут type**, чтобы QuestionEngine применил тип раунда StakeAll. Явный `simple` переопределял бы правила финала. Цена в экспортируемом финале — 0, выигрыш/проигрыш определяется ставкой игрока. Сохранённые номиналы в черновике не стираются при переключении типов раунда.

Редактор показывает список тем с единственным местом выбора вопроса. Новая тема содержит один вопрос; добавление второго, редактирование цены и выбор аукциона недоступны. Удаление единственного вопроса удаляет всю тему с подтверждением и возможностью отмены. Смена обычного раунда на финальный блокируется, если в темах не ровно по одному обычному вопросу; содержимое не обрезается. Старые неправильные финалы сохраняют все вопросы для исправления; пустая тема позволяет добавить один вопрос, лишние видны на том же поле, а аукцион можно явно перевести на правила финала. Проверка и прямой экспорт отклоняют неправильную структуру.

Импорт SIQ 4/5 сохраняется. Явный `stakeAll` поддерживается только внутри финального раунда и представлен в редакторе как вопрос, подчинённый правилам финала. Произвольные скрипты и дополнительные параметры по-прежнему отклоняются. Типы simple/default/withButton из старых финалов при следующем экспорте наследуют финальные правила.
