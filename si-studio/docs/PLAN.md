# План реализации

1. Изучить SIQ 5, XSD и правила отображения содержимого — выполнено.
2. Спроектировать структуру «пак → раунды → темы → вопросы → шаги» — выполнено.
3. Реализовать редактор, игровое поле и предпросмотр — выполнено.
4. Реализовать локальную медиатеку и автосохранение — выполнено.
5. Реализовать импорт обычных SIQ 4/5 и экспорт SIQ 5 — выполнено.
6. Проверить архив, XSD и основные действия в браузере — выполнено; детали в verification.md.
7. Опубликовать приватную рабочую версию — состояние см. в итоговом сообщении.
